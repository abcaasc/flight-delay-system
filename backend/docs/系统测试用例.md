# 系统测试用例与执行结果

当前版本验证：116 项 pytest 测试通过，并完成真实 BTS 9,000 条记录、三个 NOAA 站点的隔离链路验证。使用 Python 3.12.14 / LightGBM 4.5.0，详见 [后端优化与验证说明](后端优化与验证说明.md)。下文保留旧版测试记录，其中旧指标、环境和测试数量不代表当前版本。


> 环境：Windows 11 / Python 3.10.11 / Flask 3.1.3 / pandas 2.3.3 / pyarrow 25.0.1 / LightGBM 4.7.0
> 测试数据：BTS 2015-01（3 万行抽样，`--limit 30000`）+ NOAA ISD 2015 年 78 个站点文件
> 执行脚本：`python -m pytest tests -q`、`python scripts/smoke_test.py`

## 九、缺陷记录（开发过程中发现并已修复）

| 编号 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| D-01 | 入湖 0 行 | 数据集扫描用前缀目录匹配，`*` 通配未生效 | 改为 `Path.glob(rel_glob)` |
| D-02 | 气象写入失败 `'wnd'` | ISD 列被统一大写，解析器按小写取值 | 统一小写归一 |
| D-03 | 气象窗口 0 命中 | ODS `origin` 是 pandas `string` dtype，窗口表是 `object`，merge 不匹配 | 双侧 `astype(str)` |
| D-04 | 读表报 `Field year has incompatible types` | 分区列同时写进了文件（物理列）和目录名 | Hive 约定：分区列不落文件 |
| D-05 | 过滤 `year=2015` 返回空 | pyarrow 把 `2015` 推断成 int32，与字符串过滤器冲突 | 显式声明分区列类型为 string |
| D-06 | DWS 三率全为 0 | 聚合后列名 `_del15` 未映射到 `dep_del15_cnt`，被 schema 校验补成空列 | 统一重命名并加列名断言 |
| D-07 | 预测报 27/28 特征不匹配 | 在线特征行未做 `_feature_frame` 归一（缺 `origin_traffic_prev_day` 别名） | `predict_frame` 入口统一归一 |
| D-08 | 风速出现 999.9 m/s | ISD 缺测标记 `9999` 未剔除 | 解析时按 `>=9999` 置空 |
| D-09 | 过站时间中位数 283 分钟 | 跨机场/跨夜航段被当成过站 | 只统计「前序到达机场 == 本段起飞机场」且 10–720 分钟 |
| D-10 | 预测概率只有 0/1 两档 | 误用 `LGBMClassifier.predict()`（返回类别） | 改用 `predict_proba()[:, 1]` |

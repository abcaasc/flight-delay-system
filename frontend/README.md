# 航迹前端

Vue 3 + TypeScript + Vite + ECharts。保留墨绿导航与浅色背景，以 Card、Lucide 图标和克制的 Motion for Vue 交互组织分析工作台。

## 启动

先启动后端：

```powershell
cd backend
.\.venv\Scripts\python.exe run.py
```

另一个终端启动前端：

```powershell
cd frontend
npm install
npm run dev
```

默认打开终端显示的地址（通常为 http://localhost:5173）。默认使用“数仓数据”。本机已连接 MySQL 的 flight_delay 业务库，连接信息保存在 backend/.env；航班分析来自 Parquet 数仓，前端不需要数据库密码。

## 数据联动

- 月份、出港机场共用一个筛选范围，驱动 KPI、每日趋势、航线网络、机场排行和统计摘要。
- `/api/v1/overview` 返回关键指标与趋势；`/api/v1/network` 返回节点与航线。网络机场筛选在航线 Top N 截断前执行，日期按天过滤。
- 排行基于网络节点的当前月统计生成，与总览采用一致月份，不使用后端原先的“最近一天排行”。
- 默认读取最多 1,000 条高流量航线，地图绘制其中前 160 条本土航线；机场筛选统计出港方向，目的机场只作为关联节点。
- 切换筛选立即清空旧结果；请求可取消，并用版本号阻止慢请求覆盖新筛选。失败时显示恢复入口，不用演示结果冒充接口成功。
- 月份必须完成原始入库及 DWD/DWS/ADS 统计加工才可查询。十年全量任务进度见 backend/instance/full_pipeline/report.json；2015-01 已验证为完整的 469,968 条 BTS 航班，不能仅以 ODS 分区存在判定该月看板已就绪。
- “交互演示”明确使用模拟记录。按同一组日×航线记录聚合所有模块，月份和机场均可联动，绝不与数仓数据混用。
- CSV 导出当前机场范围及搜索结果，记录数据来源、月份、出港范围，并防止文本单元格被解释成公式。

## 构建与验证

```powershell
npm run build
npm run preview
npx playwright test
```

Playwright 使用本机 Chrome，需要前后端正在运行。覆盖真实接口筛选、无数据恢复、演示聚合一致性、导航外环、图表切页生命周期、导出和响应式布局。首次安装可按 Playwright 官方说明准备浏览器。

`dist` 为静态生产产物；生产环境将 `/api` 反向代理至 Flask，其余请求映射静态产物。开发代理位于 `vite.config.ts`，默认 Flask 地址为 `http://127.0.0.1:5000`。图表与地理模块分包按需加载。

若 Windows 临时目录导致 esbuild 报 Access denied，可将 TEMP 和 TMP 指向项目内 `.build-temp` 后重新构建，不必修改系统目录权限。

## 范围

延误预测页使用 `POST /api/v1/predict`。填写出发机场、到达机场、航司、起飞日期和当地时间后，可以查看延误概率、模型阈值、影响因素与气象来源。切换到演示数据后，页面提供返回数仓的入口。机场中文名称按 IATA 代码查找，词表覆盖当前 BTS 数仓的 390 个出港机场，使用 Wikidata 的 CC0 中文标签并依据数仓机场名称补译。

“航班查询”提供明细和机场汇总两个视图。明细可在当前月份内按日期、出发机场、到达机场、航司和执行状态筛选，每页 20 班，可导出当前页。机场排行显示延误架次、已执行架次和延误率，可设置最低执行架次，选中机场后可直接查看相应的延误航班。

“数据管理”使用应用账号登录。运行监控员及以上角色可以按状态、月份查看作业，读取月度质量报告和模型回测。管理员还可以查看失败文件与失败原因。会话凭据只保存在页面内存中。

在后端目录运行 `./.venv/Scripts/python.exe scripts/rolling_backtest.py` 可更新模型回测报告。每个窗口使用连续两个月训练、随后一个月校准阈值、再下一个月测试。报告同时比较上线模型在同一留出集上的原始特征与屏蔽前序航班特征的表现。脚本只写验证报告。

本机前端通过 `frontend/.env.local` 的 `AIRTRACE_BACKEND_URL` 连接 5001 端口的后端。新环境默认使用 5000，切换端口时同步设置后端 `PORT` 与前端代理地址。

## 地图与图标

美国州界来自 us-atlas（U.S. Census Bureau 源数据，ISC 发行），使用 d3-geo 的 Albers USA 投影，按真实机场经纬度定位；为突出本土网络，不显示 Alaska、Hawaii 等区域，但其数据仍计入统计。图标通过 Better Icons 选择 Lucide 同一线性系列，由 lucide-vue-next 在本地渲染，无外部图标请求。

总览页右上角可进入大屏；在至少 1200×800 的桌面视口中，总览按可用视口高度排布，在 1920×1080 下已验证一屏显示。按退出按钮或 Esc 返回常规布局。

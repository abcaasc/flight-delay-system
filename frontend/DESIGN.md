# 航迹设计约定

此工作台供航空数据分析人员在桌面环境长时间查看，使用浅色内容区降低图表与文字阅读负担，沿用现有墨绿导航。此文档记录当前实现与用户确认的方向，不增加营销页或装饰性场景。

- 场景：后台 BI 操作界面，优先真实统计、全局筛选一致性和清晰状态。
- 颜色：墨绿 `#143c32`、正文 `#233c35`、低饱和主色 `#31765e`、背景 `#f5f6f3`、白色 Card；浅黄绿色只用于现有品牌标记。琥珀色表示较高延误率，始终搭配数值和文字。
- 组件：共用 Card 标题、正文和底部插槽；12px 卡片圆角、7px 控件圆角，1px 细边框与低透明度向下柔和阴影。页面栅格间距 20px，窄屏 16px，卡片内间距 16—24px。
- 导航：图标加文字，选中项 1px 细边框，外环 `outline: 1px solid #8ea98c; outline-offset: 3px`。预留透明边框保证选中前后尺寸不变，键盘焦点使用更清晰的外环。
- 图标：Lucide，统一 1.6—1.7px 线宽，导航 19px、模块 18px；装饰图标不重复读屏名称，图标按钮提供标签。
- 数字：等宽数字；KPI 数值突出，统计口径贴近指标。字体使用本机 Segoe UI / Microsoft YaHei，不依赖远程字体。
- 动效：Motion for Vue 仅用于数据更新的 180ms 透明度过渡及按钮 160ms 轻微抬起/按压反馈；图表更新 180ms。尊重减少动态效果设置，无地图循环流光、模糊背景或布局属性动画。
- 数据：数仓与模拟来源显式区分。月份或机场改变时同时更新各模块。空、错、慢请求不保留旧值冒充当前范围。
- 适配：宽屏双列分析、四个独立 KPI；中屏收缩导航；手机单列图表、双列 KPI，表格内部横向滚动。

用户明确要求后台卡片和保留配色，因此 Taste Skill 的营销页整屏章节、随机换色和视觉场景规则不用于本次局部修复；沿用其统一边缘、克制动效和真实产品内容原则。
